## Learning note

A category overview should help someone recognize the type of space they are choosing. Separate compositions make small-table, family-table and private-room choices clearer than repeating a generic interior photo. Generate for the final card ratio so important chairs and room context remain visible, and keep source metadata so concepts are not mistaken for exact property photos.
